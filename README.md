# Демо-сайт-візитка «Міра Бондар — репетиторка німецької»

Статичний сайт (лише HTML і CSS, без бази даних) — приклад для показу клієнтам.
Особа, контакти й відгуки вигадані.

## Як відкрити

```bash
cd ~/Projects/demo-vizytka
python3 -m http.server 8010
```

Потім у браузері: http://127.0.0.1:8010 (німецька) і http://127.0.0.1:8010/uk/ (українська).

## Файли

- `index.html`, `impressum.html`, `datenschutz.html` — німецька версія
- `uk/…` — українська версія
- `css/style.css` — увесь дизайн (кольори зверху, у `:root`)
- `img/favicon.svg` — значок у вкладці браузера

## Як перетворити на сайт для справжнього клієнта

1. Прибрати смужку «Демо-сайт» (`demo-banner`) на всіх сторінках.
2. Замінити тексти, ціни, контакти, телефон у посиланнях `tel:` і `wa.me/`.
3. Замінити намальований портрет справжнім фото клієнта.
4. Відгуки — тільки справжні, з дозволу людей.
5. Impressum — справжні дані клієнта; Datenschutz — згенерувати на e-recht24.de.
6. Опублікувати безплатно (Netlify / Cloudflare Pages) на акаунт клієнта й підключити його домен.
